# 设计上下文 · 人生护城河 / 人生三河

- 用途：沉淀阶段 8 的稳定视觉结论，供后续页面设计、组件精修与核心体验开发读取。
- 状态：V0.1；当前 source of truth 范围为视觉方向、地图结构、视觉语义与参考资产层级。具体设计 token 与四态高保真细节尚未完成定稿。
- 最后更新：2026-09-08

## 1. 当前采用的方向

**现代编辑地图 × 轻数字山水 × 产品 UI。**

用户已选择最后确认的 Hi-Fi 版本作为当前主方向。后续沿这一体系细化，保持地图的编辑感、自然感与产品可用性。早期要求完全回到抽象母图的意见已被后续选择更新；页面允许更具象、更有空间感。

产品气质：温暖、积极、年轻、有网感、有审美、成熟克制。避免幼稚贴纸、企业 SaaS 仪表盘、心理测试网站的视觉范式。数字山水提供地形与空气感，控制传统国风符号、文旅景观与奇幻 RPG 的联想；避免鸟居、强古典建筑、大型城堡、游戏 HUD 与魔法光效。

## 2. 三河结构：强制规则

1. 核心地图始终只有三条主河，完整总览必须一眼可辨。
2. 三条主河从中央自然交汇处或共同核心区域，朝不同方向向外延伸。交汇形态有机自然，避免机械放射线。
3. 每条主河拥有自己的支流；支流在视觉层级上明显次于主河。
4. 禁止第四条平级主河；禁止额外的大河平行穿过画面；禁止以一条主河加大量分支替代三河结构。
5. 未来分叉从现有河流自然延伸，保持从属关系，不能构成新的平级主河。
6. 四个交互状态共享同一地图骨架、河道位置与页面布局。状态变化不能重新生成一套构图。

中央向外延伸是地图的组织与显现规则，无需套用真实地理水文模拟。

## 3. 底层视觉语言

| 元素 | 执行方向 | 约束 |
|---|---|---|
| 背景 | 暖象牙纸张、奶油米白，轻微纸感 | 避免纯白大底和高对比噪点 |
| 主河水体 | 低饱和深青蓝，有机河岸与轻水彩层次 | 三河属于统一水系，避免红、绿、紫三种河水 |
| 地形 | 珊瑚粉、苔藓绿、灰紫的低饱和色块 | 用于区域辨识，不能抢过河流 |
| 等高线 | 细、轻、连续，辅助表达地形 | 保持精细可读，避免密集线网 |
| 纹理 | 水彩纸感、柔和晕染 | 不牺牲文字、河岸和节点清晰度 |
| 雾区 | 明亮、半透明、边缘柔和 | 表达未知与未探索，避免灰黑、警报感 |
| 小型符号 | 克制的节点、路标、微小地标等地图语言 | 少量使用，避免图标墙和游戏道具 |
| UI | 轻卡片、弱边界、低阴影、充分留白 | 地图注释优先，避免厚重面板堆叠 |

三河差异更多通过周围地形、标签、节点与状态表达。色彩之外保留文字和形态线索。主河名称与语义见 [产品决策](PRODUCT_DECISIONS.md)。

字体延续现代编辑气质：标题可带少量人文感，正文优先清晰现代的中文阅读体验。具体字体未锁定；避免全站强国风字体。少量英文装饰不应承担关键操作或信息。

本文件不固化具体 hex、字号、圆角、透明度或组件尺寸。对话中的近似值与建议值尚不足以构成正式 token 表，后续需在真实页面中校准。

## 5. 页面与长期体验

地图是长期动态个人空间。用户持续补充经历、证明、资本与未来方向，地图随真实信息变化；每次返回都能接续自己的探索。

信息优先级：**三河地图 → 人生节点 → 当前状态 → 下一步行动 → 导航与辅助信息**。左侧导航、右侧行动区与底部状态保持轻量。空间感来自地形、留白和层次，避免通过增加复杂场景填满画面。

页面可显示更多细节，但所有景观都应支持河流、证据和探索。数据少时保留三河结构与柔和未知区域；数据多时通过分层展示和按需展开控制密度。雾的面积不用于评价人的价值。

## 6. 后续设计验收

- 第一眼识别三条主河及中央关联，每条支流归属可理解。
- 展开未来方向后仍能辨认原有三河，分叉没有升级成第四条主河。
- 页面延续当前 Hi-Fi，同时保留母图的纸感、等高线与水系语言。
- 地图拥有最高视觉权重，节点和操作能读、能点、能通过键盘访问。
- 雾保持积极开放的含义；证据、资本与结论之间可追溯。
- 交互与动效分别遵循 [交互规范](INTERACTION_SPEC.md) 和 [动效规范](MOTION_SPEC.md)。
