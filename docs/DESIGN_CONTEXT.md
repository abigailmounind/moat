# 设计上下文 · 人生护城河 / 人生三河

- 用途：主视觉、视觉语义与参考层级。阶段验收见 [进度表](../milestones.md)。
- 最后更新：2026-09-10。

## 1. 当前方向

**现代编辑地图 × 轻数字山水 × 产品 UI。** 沿用用户选定的 Hi-Fi 方向与阶段 9 接受的妥协版本；新增页面和个人数据呈现仍需各自验收。

保持温暖、年轻、成熟克制的气质。空间感来自地形、留白和层次；避免幼稚贴纸、企业仪表盘、心理测试、传统文旅景观、奇幻 RPG、大型城堡和强光特效。

## 2. 三河与视觉语义

- 始终恰好三条主河，从共同核心或自然交汇处向外延伸；各有从属支流，禁止第四条平级河流或机械放射线。
- 默认、河流摘要、证明详情、未来方向四态共用同一骨架。选择或打开详情不重新生成构图。
- 未来方向在详情及独立工作区呈现，不生成分叉水道或地图分叉标签。光泽引导线只保留为待独立确认的候选。
- 雾表示未知与未探索，不表示弱、失败或风险。已知信息、推断、缺失与证据局限靠文字说明。
- 支流粗细表达支撑强弱是产品设计目标；当前形状、宽度与雾分布仍为构图，没有个人资本计算映射。不能为了数据丰富而虚构资本或证明。

## 3. 视觉语言

| 元素 | 执行方向 | 约束 |
|---|---|---|
| 背景 | 暖象牙纸、奶油米白、轻纸感 | 避免纯白大底和高对比噪点 |
| 主河 | 低饱和深青蓝、有机河岸、水彩层次 | 三河属于同一水系，颜色差异主要交给地形与标签 |
| 地形与等高线 | 珊瑚粉、苔绿、灰紫；细而连续的轮廓线 | 辅助辨识，不抢河流视觉权重 |
| 雾 | 明亮、半透明、柔边 | 不遮挡阅读或承担唯一信息编码 |
| 节点与符号 | 少量地图锚点、路标与克制标签 | 图形大小不等于人的价值或证据权重 |
| 内容表面 | 暖纸、弱边界、低阴影与留白 | 可读、可操作，避免厚重卡片堆叠 |

正文优先清晰的中文阅读体验；题字与批注可带少量人文感。当前已登记霞鹜文楷字体仅用于指定装饰位置，见资产索引；不把它扩展为全站字体规则。颜色、字号、圆角等完整设计 token 尚未冻结。

## 4. 资产与工程关系

运行时采用地形底图、用户水彩河面资产、SVG 命中与遮罩层、DOM 标签和详情。位置共享 1672 × 941 坐标，实际文件与派生关系只在 [资产索引](../assets/README.md) 维护。

页面、渲染、个人数据投影与共享校验的职责见 [工程规范](ENGINEERING_STRUCTURE.md)。工程拆分沿用本文件的视觉方向；目录调整不构成视觉改版或全局设计 token 已冻结的依据。

| 参考 | 用途 | 使用边界 |
|---|---|---|
| 当前 Hi-Fi | 空间关系、纸感、地图与 UI 融合 | 偶然文字、错误河流数量和已取消分叉不覆盖现行规则 |
| 旧三河母图 | 水系、等高线、水彩和雾的视觉语法 | 不要求退回旧构图 |
| 视觉素材板、SVG V0.1 | 元素拆解与组件化起点 | 不等于已验收组件库 |
| AI 动效视频 | 中央到三河的显现概念 | 只作参考，不作为网页地图本体 |

源河面中的静态白纹保留；额外代码生成的常驻动态流纹已取消。不要根据旧高保真“未来分叉态”恢复已取消功能。

## 5. 全产品一致性

三河主图是全产品视觉母体。探索、结果、路径、计划和成长记录共享背景、纸感、地形、等高线与色彩气质，可按阅读或编辑任务调整密度，不必复制完整地图。

信息优先级：三河地图 → 人生节点 → 当前状态 → 下一步行动 → 导航与辅助信息。工作区使用河流轴组织层级；轴线表达关系，不另造一套河流水体。长表单自然滚动，比较表可横向滚动；背景不能牺牲文字对比、焦点或触控目标。

个人数据少时保留空状态和三河；数据多时按河、列表与按需展开控制密度。当前个人地图通过河流摘要、记录列表与文字说明查看证明，河面只投影路径空心圆和计划菱形；演示案例保留合成证明圆点。节点密度、聚合阈值和全套节点层级仍待验证，具体交互以交互规范为准。

## 6. 复核标准

核对三河层级、共享骨架、证据来源、未来方向不改变水道，以及跨页视觉连续性。布局变化还需检查长文本、键盘焦点、窄屏、触控与减少动态效果。
