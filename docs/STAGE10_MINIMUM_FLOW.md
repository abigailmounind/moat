# 当前最短探索流程

- 用途：描述可运行页面与走查入口；产品规则见 [探索规范](EXPLORATION_SPEC.md)。
- 最后更新：2026-09-10。原本地切片与后续增量的验收分别见 [进度表](../milestones.md)。
- 模块职责、校验位置与运行边界见 [工程规范](ENGINEERING_STRUCTURE.md)，启动和检查命令见 [项目 README](../README.md)。

## 1. 当前边界

入口 `/?view=explore`。本地合成规则整理回答，不调用真实模型、不要求注册。输入暂存在页面，用户确认后自主选择仅本次使用或保存到当前浏览器。

当前收集一段经历的类别、行动和结果线索，不等于完整人生访谈。界面支持多条候选的逐项处理，但本地规则不会因此自动产生复杂、多段的事实理解。

## 2. 页面顺序与继续条件

| 页面 | 当前内容 | 继续条件与边界 |
|---|---|---|
| 开始说明 | 用途、可返回与自主保存 | 主动开始，不写入个人档案 |
| 当前选择 | 继续、比较、转向、重新开始、说不清、其他 | 选一项；选其他时填写自写 |
| 决策卡点 | 六种卡点，最多两项 | 可跳过；现实条件只作为待了解线索 |
| 经历类别 | 课程 / 研究、工作、项目、协作、长期兴趣实践、其他 | 选一项，不据类别直接判断资本 |
| 具体行动 | 最多三个动作词，允许自写补充 | 至少一个动作或自写内容 |
| 结果与来源 | 最多三项结果；来源类型可不选；可主动选择只整理明确输入 | 可选择暂时没有明确结果，不编造结果或链接；手工整理仍进入逐条确认 |
| 关联依据补充 | 具体方法可不填；三种明确河流关系可多选 | 可全部跳过；只为实际填写或选择的关系生成候选 |
| 整理中 | 本地异步规则输出候选 | 成功后校验；取消或失败保留原回答，可重试 |
| 逐条确认 | 主张、经历、资本、河流、方向、未知 | 每条保留、修改或删除后方可继续；不是固定四张卡 |
| 当前确认结果 | 已确认主张、经历与关联数量、方向 | 没有保留结论时说明范围 |
| 判断依据 | 全部保留的经历及其实际关联 | 删除经历的依赖关联不进入结果 |
| 未知 | 保留的未知说明 | 没保留未知项不等于已全部知道 |
| 保存预览 | 证明、关联、候选方向和未知项 | 自主选择仅本次使用或保存到我的河 |
| 完成 | 说明实际保存结果 | 已保存可直达地图本地列表；可返回预览调整 |

自写目前位于当前选择的“其他”、具体行动补充和可选的具体方法，不能宣称所有题目均有自由输入框。快捷修改原因、完整追问和敏感主题题组仍是后续内容设计。

## 3. 确认与结果

每项显示理解正文、来源引用、条目类别及局限。修改当前条目的主文本；其他条目独立处理。操作保持卡片相对视口位置，合理恢复焦点；切屏聚焦标题。

当前规则候选数量由输入依据决定，允许资本、河流或方向为空。具体方法可产生一次人力资本实践候选；明确选择的现实支撑、跨情境复用或自主投入关系可分别产生生存、能力或热爱候选，并允许一段经历关联多条河。未补充的关系保持未知，当前不自动产生未来方向；主动手工模式只保留用户明确输入，并将资本、河流和方向保持未知。所有条目仍是待确认内容，用户可分别删除，不代表规则已判断个人的全部资本与方向。依据要求和当前切片见 [规则规范](RULES_SPEC.md)。

保存预览读取确认后的对象，不预设必须新增某条河、某个资本或固定数量的证明。候选方向保存后仍需在路径草稿中核对，才能成为长期路径。

## 4. 走查

1. 仅用选项完成输入，另走一次自写；检查返回保留、选择上限和可跳过问题。
2. 修改一项理解、删除另一项关联，检查所有结果屏与预览一致。
3. 删除经历，确认其依赖关联不进入地图；未知仍按用户选择保留。
4. 保存后返回预览调整再保存，确认本轮删除同步、其他轮次记录不丢失。
5. 从个人地图查看、删除证明；从方向进入路径草稿并保存，再次进入应打开已有路径。
6. 使用存储失败、取消及非法候选案例检查不伪报成功；长文本、窄屏与键盘另做浏览器走查。

未来内容评测可测试“确实描述了协作方式才提出社会资本”等案例。这是待评测的合理性要求，当前合成规则并未实现完整协作理解或事实判断。

## 5. 限制与证据

动作词、问题组合、确认卡数量上限和预计耗时仍待内容测试。缺失财务、身体、收入或长期偏好时不得偷偷补推；当前没有这些敏感信息的完整收集流程。

重新整理依据稳定条目 ID 保留删除；外部模型更换 ID 后的语义去重尚未接入。浏览器存储没有严格多标签原子事务；刷新或离开会丢失未保存页面草稿。

当时验收与修复见 [阶段 10 走查](reports/stage10-walkthrough.md)，后续动态确认和方向桥接见 [后续骨架报告](reports/next-foundation.md)。历史证据不代表本次文档整理重新执行了测试。
