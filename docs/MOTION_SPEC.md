# 动效规范 · 人生三河 Motion Design System

- 用途：将已验证的 AI 视频概念转为网页可控制、可响应真实数据的动画规则。
- 状态：V0.1；当前 source of truth 范围为显现顺序、事件语义与克制原则。以下具体持续时间、幅度和 easing 为建议起点，需在网页原型中校准。
- 最后更新：2026-09-08

## 1. 已验证结论

AI 视频概念已验证「人生三河从雾中逐渐生成」的方向。有效部分是中央先清晰、三河向外显现、支流随后出现、地形与节点补全，以及固定镜头下的地图生成感。

视频中的局部块状浮现、细节模糊、纹理漂移属于生成局限，不纳入正式视觉效果。正式网页使用稳定的地图元素与可控路径动画；AI 视频仅作为 motion reference，不直接使用 MP4 承载产品地图动画。

## 2. 全局原则

- 所有变化来自地图元素本身的生长、显现与局部雾变化；默认镜头固定。
- 三条主河、中央交汇和各自支流的结构贯穿全过程；动画不得生成第四条平级主河。
- 长期常驻动画极弱；用户触发的变化更明显，结束后回到安静状态。
- 地形轮廓、等高线、文字与节点位置保持稳定，不持续漂移。
- 用动画解释已发生的数据变化，不通过动画虚构资本增长或新证明。
- 避免自动推镜、快速缩放、旋转、强光、粒子爆炸、弹跳与河道随机形变。

## 3. 首次进入地图：建议时间轴

以进入地图且已有可展示数据为起点；时间区间允许重叠。完整展示约 4.8 秒，提供跳过或立即查看的方式；常规返回建议直接呈现稳定地图。

| 时间区间 | 建议过程 | 实现要求 |
|---|---|---|
| 0–0.8 秒 | 暖纸底与浅雾出现，中央核心先清晰 | 局部 mask 与透明度变化，避免整图统一淡入 |
| 0.8–2.5 秒 | 三条主河从中央交汇处向外生长 | 沿既定路径 reveal；三河开始时间依次错峰 100–200ms |
| 1.8–3.5 秒 | 各自主河的支流随后生长 | 相应主河段先可见，再显现其支流；支流组可错峰 100–200ms |
| 2.5–4.2 秒 | 地形色块、细等高线与证明节点逐层显现 | 地形先稳定，节点随后轻显；避免全部元素同时出现 |
| 3.5–4.8 秒 | 过渡雾退到外围，进入稳定状态 | 保留真实未知区域的雾，不能为了动画收尾把未探索区域全部清空 |
| 完成后 | 极弱水流与雾呼吸 | 仅环境层循环，文字与操作区稳定 |

中央可在早期出现极淡地形线索，完整地形与节点遵循后段时序。建议主河生长采用温和 ease-in-out，雾散与元素显现采用 ease-out。不能仅把完整河流整体淡入来代替沿路径生长。

## 4. 动效参数建议

| 类别 | 持续时间 / 周期 | easing 建议 | 幅度与约束 |
|---|---|---|---|
| 河流 Hover / 焦点强调 | 160–240ms | ease-out | 小幅透明度或强调层变化，保留其他河流可读性 |
| 标签与详情出现 | 180–280ms | ease-out | 以 opacity 为主，可有极小位移，无弹跳 |
| 节点浮现 | 300–450ms | ease-out | opacity 由 0 到 1，可配 scale 0.96 到 1 |
| 支流生长 | 700–1200ms | ease-in-out | 沿路径显现，归属主河清楚 |
| 支流变粗 | 600–1000ms | ease-in-out | 从旧数据宽度过渡到新数据宽度，末态由数据决定 |
| 未来水道显现 | 800–1400ms | ease-in-out | path reveal 配合局部雾 mask，细于主河 |
| 局部雾散 | 900–1600ms | ease-out | 只作用于本次探索对应区域 |
| 水流常驻 | 16–24 秒循环 | linear | 极弱流纹，低对比、无明显波峰，不改变河岸 |
| 雾呼吸 | 12–20 秒往返周期 | ease-in-out | 透明度相对基值建议仅变化 0.02–0.04；不反复遮挡信息 |

需要统一曲线时，可从 ease-out `cubic-bezier(0.22, 1, 0.36, 1)` 与 ease-in-out `cubic-bezier(0.45, 0, 0.55, 1)` 开始调试。数值属于实现建议，不能反推为已确认的视觉 token。

## 5. 产品事件与反馈

| 事件 | 地图反馈 | 语义与顺序 |
|---|---|---|
| 新证明加入 | 对应节点轻轻浮现 | 先确认记录已成功加入，再显现节点；若资本也有依据发生变化，再联动支流 |
| 新资本被发现 | 对应支流沿路径生成 | 所属主河保持稳定；与已有资本增强区分 |
| 已有资本增强 | 对应支流缓慢变粗 | 仅对真实更新的支撑关系过渡，不自动扩大整张地图 |
| 新方向形成 / 打开未来分叉 | 细小未来水道从雾中显现 | 区分方向数据新增与已有方向的视图展开；展开不重复创建记录 |
| 完成探索 | 对应局部雾散开 | 如本次还新增资本或证明，可依次显示支流与节点；仅执行实际发生的变化 |

同一次探索涉及多种变化时，建议「局部雾散 → 支流生成或更新 → 节点浮现」，事件组错峰 100–200ms。首次进入的主河生成序列与日常更新序列分别使用，局部更新不重播整张地图。

## 6. 网页实现建议

- 使用 **SVG 地图 + React / DOM 叠层**。SVG 承载三河、支流、地形、等高线、雾 mask 与未来路径；DOM 承载可访问的标签、节点操作与详情。
- 简单过渡可用 CSS；状态联动可用 Motion；复杂时间轴按需使用 GSAP。无需同时引入所有动画库，具体依赖随工程确认。
- 线状路径可用 `stroke-dasharray` / `stroke-dashoffset` 实现 reveal。填充形态的宽河道可用沿中心路径生长的 mask 显现河面，保持既定河岸形状。
- 支流变粗可使用 stroke width 或 mask 过渡；填充河道需要兼容的几何或遮罩方案，避免任意 path morph 导致轮廓跳变。
- 雾与地形使用局部 mask、opacity 与适量 blur；文字与交互层不参与模糊。blur 效果限制区域，避免整个页面持续重绘。
- 地图与 DOM 叠层共用位置映射，窗口变化后标签和节点仍贴合地图。
- MVP 不优先 Three.js / WebGL；真实水彩流体模拟、复杂三维场景属于后续评估范围。

本节仅定义实现方向，不指定组件文件名、目录架构或工程依赖版本。

## 7. 中断、性能与减少动态效果

- 切换状态时取消已失效的动画，平滑落到当前有效状态；重复点击不堆积时间轴。
- 用户跳过入场后立即显示完整的当前已知地图，保留未知雾区。数据、操作与焦点不等待动画结束。
- 页面隐藏、离开视口或卸载后暂停常驻循环；恢复时显示当前状态，不补播积压动画。
- 提供停止环境动态的方式；在低性能环境优先停掉雾呼吸和水流纹理，保留静态清晰地图。
- 检测 `prefers-reduced-motion: reduce`：关闭入场路径生长、常驻水流、雾呼吸、缩放和位移；直接展示末态，必要反馈使用即时更新或不超过 100ms 的轻透明度过渡。
- 减少动态效果时，新节点、支流与方向仍通过文字状态说明和明确选中态传达；可用礼貌的状态播报告知更新，避免播报每一帧。
- 动效不能承担唯一的信息编码；键盘焦点、说明文字和可操作入口始终保留。

## 8. 验收

验证首次显现的顺序、固定镜头、100–200ms 错峰与安静末态；检查局部事件只影响关联区域、未探索雾正确保留、快速切换无动画堆积。开启减少动态效果后，完整走通四态交互，信息与数据结果应相同。

## 9. 2026-09-08 实现校准

src/map.js 使用填充河岸与中心路径遮罩；src/styles.css 控制显现和环境循环。主河从 0.8 / 0.95 / 1.1 秒开始，持续 1.65 秒；支流从 1.8 秒后错峰，地形在 2.5 秒后显现，节点在 3.4 秒后显现，总序列 4.8 秒。未知雾不随收尾消失。

流纹以 20 秒周期改变 dash offset，河岸不变；雾以 16 秒在 0.68–0.72 间呼吸。暂停后偏移保持原值；页面隐藏暂停环境循环。系统或页面减少动态效果均直接显示末态。回访偏好仅保存在 sessionStorage 中，不含个人资料；存储不可用时仍可进入地图。

这些是本轮可运行参数，仍属待视觉验收的校准值。浏览器实测和限制见 reports/stage9-verification.md。
