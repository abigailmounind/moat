# 动效规范 · 人生三河

- 用途：当前动效规则、数据事件边界与降级要求。
- 最后更新：2026-09-10。验收状态见 [进度表](../milestones.md)。

## 1. 现行边界

沿用固定镜头、中央到三河的显现与安静末态。AI 视频只作概念参考，不用 MP4 承载产品地图。

运行时不生成额外常驻水流纹理；河面保留源资产的静态白纹。未来方向只更新详情，禁止以新水道显现或地图分叉标签作为默认反馈。旧时间轴中的流纹与未来水道方案已撤销，见历史报告。

文字、地形和交互位置不持续漂移；避免自动推镜、随机河岸形变、弹跳、旋转与强光。动画不创建数据，也不制造资本增长。

## 2. 当前实现与时间轴

实现位于 `frontend/src/map.js`、`frontend/src/styles.css` 与 `frontend/src/app.js`；CSS 存在历史覆盖规则，修改前核对最终生效值，不仅搜索第一次声明。

| 部分 | 当前行为 |
|---|---|
| 初次进入 | SVG 遮罩沿既定河道从核心向外显现，支流随后出现；页面提供“立即查看地图” |
| 河面完成显现 | 从 2.75 秒起用 1.45 秒柔和透明度交叠，避免完整遮罩突然接管 |
| 总序列 | 约 4.8 秒结束，保留未知雾 |
| 常规返回 | 当前标签页的显现偏好保存在 sessionStorage，已经看过时直接呈现；存储不可用不妨碍使用 |
| 稳定状态 | 极弱雾呼吸，水面静态；可暂停或开启减少动态效果 |
| 详情与选中 | 主河光线沿水彩河面校准，选中后从交汇处向外柔和展开，退出淡出；减少动态效果时立即显示。不改变地图几何 |

这些是当前实现参数，不是全部冻结的设计 token。主河、支流、地形与节点的精确延迟以源码为准，不在多个文档维护第二套数值。

## 3. 数据变化与反馈

| 事件 | 当前可执行反馈 | 后续条件 |
|---|---|---|
| 保存证明成功 | 更新记录、数量与可用入口；返回地图可查看 | 节点局部显现需独立验证，失败不能伪报加入 |
| 确认或撤回关联 | 更新文字与关系，保留稳定构图 | 不自动改变支流粗细 |
| 打开或保存方向 | 展示详情或带入路径草稿 | 不生成地图水道；展开不重复保存 |
| 完成行动或里程碑 | 保存完成状态 | 不自动增加资本、生成证明或清除雾 |
| 完成探索 | 展示已确认内容与保存结果 | 不以完成问卷为理由清空未知 |

新支流生成、资本增强后的变宽与局部雾散仍是依赖定性映射和视觉验证的后续目标，当前未接入个人数据。即使未来实现，也只作用于有依据的变化区域，不能重播整图冒充成长。

## 4. 中断与减少动态效果

- 数据与操作不等待动画完成；立即查看、暂停和关闭应随时可用。
- 失效状态或重复操作不得堆积动画，返回时使用当前有效状态。
- 页面隐藏时暂停环境循环，恢复后不补播积压序列。
- 系统 `prefers-reduced-motion: reduce` 或页面选择应关闭入场生长、环境呼吸及位移，直接显示完整信息；保持焦点与文字状态。
- 动画不能作为唯一的信息编码；键盘与触控具有等价入口。
- 低性能优化优先减少模糊和环境循环，保留清晰的静态地图。

当前以 CSS 与 SVG 实现，DOM 承载可访问交互。模块依赖、异步取消和资源释放遵循 [工程规范](ENGINEERING_STRUCTURE.md)；运行检查入口见 [项目 README](../README.md)。外部框架与动效库不属于当前依赖，调整技术栈需沿用 AGENTS 的范围与授权规则。

## 5. 验证

涉及动效改动时检查首次、跳过、重播、暂停、切换面板、页面隐藏及减少动态效果；检查三河结构与未知边界保持一致。

自动检查不能代替浏览器实测和视觉验收。已发生的动效检查见 [阶段 9 报告](reports/stage9-verification.md)，其他证据按 [文档导航](README.md#验证证据与历史入口) 查阅。本次文档整理未重新测试或修改动画。
