# 阶段 7C 图示说明

本轮依据已确认的 7A、7B 与 V2 逻辑制作两张低保真结构图，不新增需求或锁定高保真视觉。

## 两张图分别解决什么问题

- **MVP 端到端总览（2400 × 1570）**：作为产品地图 V2，展示首次体验、六段结果、保存与注册、长期使用的页面及模块关系。长期首页提供未来路径、护城河建设、我的与隐私三个入口。实线表示进入或顺序，虚线表示路径对建设的方向关联。图中 AI、评分和保存节点是过程或状态，不强制对应独立页面。
- **黄金路径流程（2400 × 1770）**：展示用户、AI、系统的职责及交接。三条泳道按 A 探索与结果、B 保存与建设、C 行动与更新连续展开，按 01–27 编号阅读，跨阶段箭头连接真实前后步骤。

## 与 IA / User Flow V1 的区别

依据对话对 V1 的描述，IA V1 主要回答“有哪些页面”，新用户 User Flow V1 主要回答“第一次如何走到结果与我的护城河”。本轮 V2 在此基础上补足结果之后的长期闭环，并明确权限、保存与模型关系；未对未提供的原始 Figma 文件进行逐节点比对。

## 7C 新增或修正

1. **一个个人系统，多条未来路径**：路径提供方向，护城河建设组织三河与五资本的积累。建设计划不等于某一路径的 90 天任务清单，里程碑及成果可支持多个方向。
2. **完整闭环**：里程碑 → 成果证明 → AI 提议资本关联 → 用户确认 / 修改 → 规则重算资本与三河 → 历史变化 → 更新首页。完成行动或上传证明本身不会自动加分；重算也不承诺必然增长。
3. **确认边界**：AI 提议理解、路径、建设草稿与资本关联；用户确认或修改；系统保存和执行。所有百分比来自评分规则，AI 根据系统结果生成解释。
4. **隐私边界**：完整结果先于注册。保存前仅在当前会话暂存，建立护城河时确认保存范围；完整探索记录与敏感区间可不保存，敏感题可跳过。用户在“我的与隐私”拥有编辑、删除和范围管理入口。
5. **首次长期体验**：首页承接已保存地图；无计划时引导查看路径、生成可编辑建设草稿。
6. **高保真待探索**：三河流域 + 五资本支流 + Milestone 节点 / 梯度。本轮仅表达信息关系。

## SVG 交付与导入

两张图均为独立 SVG，采用原生 text、rect、polyline、polygon 和具名 g 分组；不依赖外部图片、脚本、网页嵌入或字体文件。箭头由线与三角形组成，便于导入后的编辑。总览按模块分组，泳道按角色及步骤分组。将 SVG 拖入 Figma 画布即可导入；文字在 SVG 源文件中保留为 text，Figma 导入后的文本处理取决于导入器。未执行 Figma 实机导入验证。建议使用 Microsoft YaHei 或 Noto Sans CJK SC，以减少字体替换差异。
