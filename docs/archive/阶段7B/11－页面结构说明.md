# 人生三河 · 阶段7B 页面结构说明

这组灰度低保真稿仅覆盖长期产品核心闭环。单页 390 × 1040，可纵向滚动；底部导航在实现时固定。SVG 保留文本与分组，可导入 Figma 后继续重建。SVG 展示页面与关键状态，按钮本身不执行跳转。

所有人名以外的内容、分数、日期和进度均为演示数据，不定义正式评分权重或百分比算法。第2页为添加本次成果前，第9页为成果加入后；返回第2页时韧性河变为53%，重点与最近变化读取新结果。百分比统一用 %，差值采用“百分点”。

主流程：01 → 02 → 03 → 04 ↔ 05 → 06 → 07 → 08（识别 → 用户确认 → 评分系统计算）→ 09 → 02。第4页可直接进入第6页，第5页保存后返回第4页。

## 01 建立我的护城河

- 页面目标：保存当前探索，开始长期使用。
- 模块顺序：保存说明 → 保存内容 → 隐私范围 → 建立按钮
- 主要按钮与去向：建立我的护城河 → 必要时登录 → 保存成功进入第2页；调整保存范围 → 本页设置层。
- 人工智能参与：沿用已有分析，不在保存时追加分析。
- 用户可编辑：保存项目、完整探索记录开关、敏感信息保存范围。

## 02 我的河首页

- 页面目标：看清当前重点，继续最近的一小步。
- 模块顺序：三河概览 → 当前重点 → 下一里程碑 → 最近变化 → 新进展 → 导航
- 主要按钮与去向：继续推进 → 第7页；记录新进展 → 第8页；未来路径 → 第3页；护城河计划 → 第6页。
- 人工智能参与：展示已有分析与评分结果，不因浏览页面重新计算。
- 用户可编辑：通过对应详情编辑计划、里程碑与成果。

## 03 未来路径列表

- 页面目标：管理正在考虑的未来方向。
- 模块顺序：引导 → 初始化说明 → 路径卡片 → 新建 → 导航
- 主要按钮与去向：查看路径 → 第4页；新建 → 第5页空白状态。
- 人工智能参与：初始化路径及参考指标；用户持续编辑。
- 用户可编辑：通过第5页新建、修改、暂停、删除路径。

## 04 路径详情

- 页面目标：理解路径价值、差距与验证方式。
- 模块顺序：路径状态 / 编辑 → 选择理由 → 指标 → 积累与缺口 → 验证 → 制定计划
- 主要按钮与去向：制定计划 → 第6页待确认初稿；编辑或管理 → 第5页；查看依据 → 本页解释层。
- 人工智能参与：生成理由、差距、验证建议与计划初稿。
- 用户可编辑：在第5页修改路径信息；计划在第6页继续编辑。

## 05 新建或编辑路径

- 页面目标：用轻量表单持续调整路径。
- 模块顺序：名称 → 动机 → 状态 → 验证方式 → 保存 / 补充建议 → 管理区
- 主要按钮与去向：保存 → 第4页；补充建议 → 表单中待采纳建议；暂停 → 原位确认状态；删除 → 确认层 → 第3页。
- 人工智能参与：按用户输入补充建议，采纳后才进入表单。
- 用户可编辑：名称、动机、状态、验证步骤；暂停后可恢复原状态。

## 06 护城河计划首页

- 页面目标：将路径变成可编辑、可推进的行动安排。
- 模块顺序：关联路径 / 目标 → 里程碑列表 → 继续推进 → 编辑计划 → 导航
- 主要按钮与去向：初稿确认 → 本页已启用状态；继续推进 → 第7页；编辑计划 / 添加里程碑 → 本页编辑层。
- 人工智能参与：首次生成目标与里程碑初稿，不自动覆盖后续用户编辑。
- 用户可编辑：目标、时间、里程碑内容与顺序；新增、修改、移除里程碑。

## 07 里程碑详情

- 页面目标：推进一个里程碑，并留下成果。
- 模块顺序：完成标准 → 进度 / 日期 → 关联资本 → 已有证明 → 添加成果 → 编辑
- 主要按钮与去向：添加成果 → 第8页并带入里程碑；编辑 → 本页编辑层；查看证明 → 本页详情层。
- 人工智能参与：关联资本为计划建议，最终以成果识别及用户确认结果为准。
- 用户可编辑：标题、完成标准、进度、日期、摘要；达到标准后可标记完成。

## 08 添加成果证明

- 页面目标：记录成果，确认资本关联后再更新分数。
- 模块顺序：成果表单 → 隐私提示 → 识别按钮 → 关联确认区 → 确认并更新 → 草稿
- 主要按钮与去向：识别 → 本页第二步；修改关联 → 本页资本选择层；确认并更新 → 计算成功进入第9页；草稿 → 返回来源页。
- 人工智能参与：仅负责识别关联资本并给出依据；用户确认后由评分系统计算。
- 用户可编辑：名称、摘要、可选材料、关联里程碑、资本勾选；识别后编辑材料需重新识别并确认。

## 09 三河更新反馈

- 页面目标：反馈更新结果，接回下一步行动。
- 模块顺序：成果与确认资本 → 三河前后变化 → 判断说明 → 下一步 → 返回 / 继续
- 主要按钮与去向：回到我的河 → 第2页最新状态；下一里程碑 → 第7页下一项；查看依据 → 本页更新记录层。
- 人工智能参与：说明基于实际评分结果生成，不擅自承诺或调整分数。
- 用户可编辑：成果详情中可修改；修改后需重新确认关联并重新计算。

## 核心状态与交互约定

- 第8页同时呈现两个顺序状态以便评审：初始仅展示记录区与识别按钮；识别完成才显示确认区。用户至少确认一个资本后才可提交。拒绝所有建议可保存草稿或手动选择。识别不等于保存或评分。
- 提交后禁用重复提交；评分失败时成果保留为待更新，允许重试，不重复增加记录。成功后记录评分版本、前后值及依据；没有有效变化时显示持平。
- 来自里程碑的成果，核对完成标准后提示用户确认是否标记完成。第9页示例已确认完成；一般记录新进展时，不强制关联里程碑。
- 百分比解释层分别说明指标含义、所依据的已确认材料、更新时间与信息不足；转换成本越低表示预计新增投入越少。参考指标不表示成功概率。正式口径沿用既有评分规则，本稿不新增算法。
- 暂停路径保留记录，停止推进提醒，关联计划显示暂停，可恢复；删除必须二次确认，明确显示关联计划影响。删除路径后计划解除关联并保留，成果证明保留；用户另行管理保留内容。
- 计划和里程碑编辑在本页编辑层完成，支持保存与取消。移除已有成果的里程碑需确认，保留成果并解除关联。人工智能再生成时先展示待采纳建议，不覆盖已保存内容。
- 隐私默认最小化保存。完整探索记录和附件默认不选；敏感字段可跳过。保存范围调整发生在第1页设置层。此前明确的用户选择优先沿用。
- 各列表为空时显示简短说明与对应创建按钮；分析或初始化失败保留输入并提供重试；返回未保存表单提示保存草稿或放弃修改。
- 底部「我的」沿用已有个人与隐私设置，不在本轮新增页面。弹层与编辑态在本文定义，未额外扩展为第十张移动页面。

## 导入与评审

将单页 SVG 拖入 Figma 画布。文字使用系统中文字体，导入设备缺少对应字体时需替换中文字体。每页保留文本和区块、按钮、导航分组；导入后需重建自动布局、组件与真实原型连线。总览用于检查流程与信息层级，单页用于编辑。
