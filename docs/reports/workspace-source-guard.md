# 跨保存位置保护

日期：2026-09-11。

发现：删除连接后，其他标签的旧服务器快照可能走本地提交分支，把旧服务器内容写入原始本地工作区。

修复：连接层用 WeakMap 记录读取快照与保存结果的来源。保存、删除、确认、撤回前检查来源是否仍相同；服务器提交在取得跨标签锁后再检查。异步结果沿用操作开始时的来源，避免等待期间来源变化误标记。来源不进入持久化或导出。

回归覆盖另一标签删除连接后四类写操作均拒绝、本地副本保持不变、重新读取后正常本地保存、切回服务器后旧本地保存结果也被拒绝。npm test：21 个测试文件通过；npm run check、git diff --check 通过。

限制：内存来源依赖调用方保留原 base 引用，工程规范已说明；服务端仍独立校验权限与版本。真实浏览器多标签、下载及 PostgreSQL 验证未执行。已有删除待核对刷新恢复与缓存失败测试继续通过。备份恢复尚未实施，留作后续切片。
