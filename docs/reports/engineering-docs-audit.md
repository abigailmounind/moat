## 纠正的表述与工程剩余项

- 最短探索流程原来固定写“一条能力河候选”；当前规则会依据输入产生三河之一，已改为引用探索规范的映射。
- 设计上下文原来写“每河最多一个证明入口”，容易误解为个人地图仍有证明圆点；已按 app 的渲染区分个人工作区标记与演示证明节点。
- 后端架构曾将可调用接口和规划接口混列，已逐项标明；服务端分析、确认、导入、导出和账号删除尚未实现。能力枚举不能证明这些接口存在。
- 聚合工作区结构校验保留旧档案兼容；新建归属、移河及删除影响还有前端操作层规则。正式服务端纵向切片须补齐操作级校验。
- 分析服务仍 import 前端候选校验；CLI 另有独立检查。已列入工程依赖例外，文档没有声称完成全部共享领域抽取。
- 个人摘要证明按钮未显式传递所属河，跨河证明会落回证明默认河；已在交互规范与 milestones 记录待修复，未在文档任务中改代码。
- 旧报告的“最近/当前”仅指当时；现行文档统一从验证导航定位证据，不把历史报告冒充最新进度。
