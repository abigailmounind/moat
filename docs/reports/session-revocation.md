# 会话退出基础

日期：2026-09-11。

## 实现范围

作为账号阶段的独立服务端切片，新增 DELETE /api/v1/session 与两种仓储的 revokeSession。仅撤销 Cookie 对应令牌；成功后清 Cookie，保留主体、工作区和回执。不需要迁移数据库结构，不接外部认证供应商。

同源检查在撤销前执行。重复、未知或空令牌可安全重试；仓储抛错或未返回成功时返回 503，保持 Cookie，不显示虚假成功。其他会话继续有效。

## 验证

- npm test：23 个测试文件通过；不将文件数当作内部用例数。
- npm run check：30 个浏览器/共享模块及静态保护检查通过。
- npm run check:api：独立临时服务，新增退出、Cookie 到期、旧令牌拒绝与重复退出检查通过。
- npm run check:postgres：PostgreSQL 16.4-alpine 独立临时容器、随机 schema。共享撤销专项验证数据与回执保留、主体隔离、重复退出、新匿名主体为空；HTTP 退出后重启 Node，旧令牌仍不可用，主体数据仍存在。既有数据库生命周期专项全部通过。

临时容器停止后自动移除，未读取或修改个人浏览器内容及生产数据库。

## 限制与下一步

当前交付限服务端会话能力，没有页面退出入口。匿名用户尚无账号恢复方式，UI 接入须同时处理恢复说明、缓存隔离和待提交请求；不能把退出当作删除数据。会话检查已通过的在途请求可能完成，不承诺取消已接受的写入。

账号认证方式仍待用户确定，未接入供应商、注册、登录、匿名转账号或跨设备恢复。后续按确认方式推进，真实浏览器验收贯穿页面变更。本轮没有部署或推送。
