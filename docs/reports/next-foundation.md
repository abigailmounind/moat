# 后续骨架交接 · 2026-09-09

用户授权：暂时不能逐步亲自验收，允许尽量继续修复并搭建后续骨架。本轮沿用三河主视觉与本地存储，没有改动地图资产、安装项目依赖、启用付费模型、发布或迁移云端数据。既有工作区修改保留。

## 已实现

| 模块 | 当前行为 |
|---|---|
| 工作区边界 | 展开河流、路径或切换成长记录分组保留当前输入；保存失败时完成勾选回到原值；旧独立计划编辑不自动选择路径 |
| 路径与计划 | 移动路径河流时同步单路径计划；旧同河多路径可保留，跨河旧计划等待明确归属；计划详情恢复成长记录入口 |
| 里程碑与历史 | 独立添加、编辑里程碑；删除计划或路径后成长记录保留历史分组上下文；成果快照继续独立确认 |
| 探索确认 | 根据候选生成逐条确认卡，支持多经历、多关联、方向与未知项；结果显示实际确认对象；删除经历过滤依赖关联 |
| 探索保存 | 合并其他探索的独立更新，拒绝已检测到的同条目陈旧覆盖；损坏档案不覆盖 |
| 我的河 | 默认显示个人确认记录及空状态；摘要与证明数量来自档案；每条河最多露出一个证明入口，全部记录可从列表与文字说明查看；合成案例位于 `?demo=1` |
| 方向转路径 | 先带入可编辑草稿，再由用户保存；保存后重入打开已有路径；检测到其他页面已建立同方向路径时拒绝重复保存 |
| 模型接入边界 | 服务端能力查询、分析入口、来源及大小限制、超时、格式与引用检查；客户端取消与响应检查；默认没有供应商，界面仍用本地规则 |

1. 集中验收本轮完整链路和视觉：探索逐条确认 → 保存到个人地图 → 从未来方向核对并保存路径 → 路径下计划和里程碑 → 成果回流。额外检查长文本、键盘焦点和窄屏。
2. 校准真实模型接入前的内容案例：信息不足、只有偏好、多段经历、冲突、用户删除与修改。当前合成规则范围有限，不代表真实 AI 理解质量。
3. 明确供应商与数据处理边界后接入一个模型。结构校验不能证明事实；还需敏感信息跳过、事实支持、限流、成本、外部输出改变条目 ID 时的语义去重及用户修改优先。服务接口目前只作为本地接入骨架，不作为生产 API。
4. 再确定登录、账号、本地到账号迁移和云端同步。当前多标签检查能识别部分陈旧提交，本地存储没有原子事务；刷新前未保存草稿没有自动恢复。
5. 进行自愿真实用户走查，记录实际问题与修复，随后才整理阶段 13 产品案例与发布门槛。合成测试不替代真实反馈。
