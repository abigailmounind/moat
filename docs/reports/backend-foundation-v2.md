# 后端地基第二轮 · 工程验证

- 日期：2026-09-10。
- 范围：接续现有后端主线，完成开发态聚合工作区的共享校验、幂等重试与可异步替换仓储接口。
- 当前契约见 [产品 API](../PRODUCT_API.md)，下一步见 [milestones](../../milestones.md)。

## 本轮形成的产物

1. `shared/profile.js` 与 `shared/workspace.js` 承接档案、成果快照和工作区结构校验。前端原模块保留重导出；本地保存、表单和地图展示沿用已有流程。修复非法里程碑引用导致校验抛异常的边界。
2. `backend/product-repository.mjs` 独立内存适配器；产品服务等待所有仓储调用。对读取或写入异常返回通用 503，保留可靠数据，不暴露内部错误。
3. 工作区 PUT 支持可选 `Idempotency-Key`，验证同键重放、异内容冲突、不同主体隔离、回执容量与过期边界。版本、工作区与回执在内存同步段内一起更新；此能力尚未接数据库。
4. `npm run check:api` 提供真实 HTTP 自动冒烟；独立临时端口启动并关闭服务，检查 23 个浏览器模块、会话、并发重试、冲突和静态文件边界。共享文件仅按两个明确公共路径开放。

## 限制与后续

- 本轮没有布局或资产变更；DOM 与模块加载检查不代表真实浏览器视觉、窄屏、触控或用户验收。
- 当前前端仍默认本地保存，尚未消费服务端幂等 API 或同步数据；服务重启会清空内存工作区、会话及回执。
- 数据库类型落定后的持久适配器、真实事务、对象级接口、正式会话生命周期、账号与迁移仍需实施。异步包装测试不能替代真实数据库验证。
- 本轮未调用外部模型、选择云服务或产生部署费用；未提交 Git，保留接手时已有的工作区修改。
