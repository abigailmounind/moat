## 计划入口

原有新建计划按钮只在已有路径下面出现。新域名的本地工作区为空，没有路径时所有新建计划按钮都消失，概览也隐藏了详情区的说明。

计划页现始终提供「新建计划」按钮。已有路径时打开草稿并要求明确选择归属；没有路径时说明先建路径，并提供各河「先新建路径」链接，直接进入对应河的路径编辑器。保存路径后可从详情继续创建计划。没有放宽单路径归属、河流继承或资本必填规则，没有迁移旧站点数据。

- 新增空工作区、已有路径和显式归属的渲染回归。
- 本地及远程真实 Chromium 在 1440px/390px 走完：空态入口、键盘 Enter、新建路径、计划保存、刷新、未选路径拒绝、取消、第二条计划及继承热爱之河。
- 无横向溢出和页面异常。截图检查布局可用；临时系统缺少中文字形，字体视觉仍未验收，触控为模拟。

## AI 配置与工程修复

- 原规则版预发布按授权关闭模型；本轮用户确认模型免费保护后，使用现有新加坡普通 Key，通过标准输入上传为隔离 Worker Secret；不写入源码、Pages 产物或日志。
- 最终 Worker 版本：`861a0832-f598-417c-b920-655d12e9aeaf`。沿用已配置后台白名单，日上限收紧为全局 20 次供应商尝试；每主体每小时 6 次，单在途，75 秒超时。默认仍为规则，探索补充页勾选本轮云端处理同意后才发模型请求。
- 首次真实调用在出站前失败。固定诊断类别显示 transport；本地 workerd 复现 `redirect: error` 不受支持。改为 `manual` 并在读取响应体之前拒绝所有 3xx，不跟随 Location 或转发凭证。
- 补充完整候选 JSON Schema、同输入生成的保守规则参考及推断边界。输出仍经共享校验、逐条确认和独立保存；不把格式通过当作事实验证。
- 修复后的 workspace 专属端点真实请求仍在 75 秒超时；按官方接口关闭默认思考并限制最多 4096 输出 token 后仍超时。同一 Key、同一首选模型在新加坡标准端点的合成输入对照返回 HTTP 200，并通过共享结构校验，因此隔离 Worker 改用 `https://dashscope-intl.aliyuncs.com/compatible-mode/v1`。Node 的原 `.env` 未改，专属端点超时的供应商内部原因未知。截断或无效输出继续回退规则。
- 失败日志仅固定原因类别和整数 HTTP 状态码，不记录原始回答、模型输出、提示词、Key、Cookie 或供应商错误正文。

依据：[Cloudflare Request 参数](https://developers.cloudflare.com/workers/runtime-apis/request/)、[百炼思考模式](https://www.alibabacloud.com/help/en/model-studio/deep-thinking)、[百炼 OpenAI 兼容接口](https://www.alibabacloud.com/help/en/model-studio/qwen-api-via-openai-chat-completions)、[Free Quota Only](https://www.alibabacloud.com/help/en/model-studio/new-free-quota)。用户确认是免费保护的依据，本仓库没有权限独立审计控制台计费状态。
