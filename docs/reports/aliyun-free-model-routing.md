# 阿里云百炼免费模型路由验证

- 日期：2026-09-12
- 范围：服务端配置与模拟 HTTP/供应商回归；未使用真实 API Key、未产生外部调用或费用。

## 已形成

- `backend/aliyun-model-provider.mjs` 只接受百炼新加坡国际兼容端点或该地域 workspace 专属端点，明确拒绝 trial、Token Plan 和 Coding Plan 端点；普通 API Key、后台模型白名单及 `ALIYUN_FREE_ONLY_CONFIRMED=true` 缺一即关闭。workspace 专属端点必须配同一 workspace 创建的 Key。
- 用户不选择模型。服务端按白名单顺序调用；收到 `403 AllocationQuota.FreeTierOnly` 后在当前进程熔断该模型并尝试下一项，429 可切换，普通失败不跨模型重试。
- `POST /api/v1/analyses/model` 要求有效匿名会话、同源 JSON 和合法探索输入。发送前裁剪为允许字段，响应不包含具体模型名；候选仍经过共享契约校验。
- 模型失败、超时或额度耗尽明确返回规则候选及 `fallbackFrom` / `fallbackReason`。旧 `/api/analysis` 不接入真实供应商。
- 同一会话只允许一个模型请求在途，默认每小时最多 6 次；超额或并发请求在供应商调用前返回 429。该内存保护不能代替公开部署时的边缘/IP 限流。
- 进程内每日硬上限是额外保险，不是计费事实来源；真正防欠费依赖百炼控制台对所有白名单模型启用 Free Quota Only。

## 尚未开放

页面默认使用本地规则。仅当服务端能力确认 Free-only 模型已配置，且用户在本轮主动勾选外部处理同意时，才发送允许字段到百炼新加坡；同意不持久化，不显示或选择具体模型。云端失败后明确显示本地规则回退。该交互已通过模拟服务的桌面/窄屏真实浏览器验收。公开前还需要：在控制台持续核对白名单模型及逐项 Free Quota Only；增加 Cloudflare/IP 限流和防滥用；完成剩余固定内容及真实模型质量评测。未来可移植到 Cloudflare Workers + D1，当前 Node + PostgreSQL 实现保留。

## 首次真实通道核对

用户于 2026-09-12 提供百炼控制台统计：`qwen3.8-flash` 1 次、平均 23.9 秒；`qwen3.8-max-0902` 2 次、平均 58.93 秒；三次供应商侧失败率均为 0%。这说明此前 20/25 秒本地超时会把供应商最终成功误判为失败，且中止没有阻止供应商完成。服务默认超时因此调整为 75 秒并允许环境配置至 120 秒；模型顺序保持 Flash 优先。该统计来自用户控制台，不等同于本仓库独立计费审计或长期性能结论。
