# 探索确认档案连接与同步验证

日期：2026-09-12。范围：浏览器本地与服务端探索确认档案的显式切换、复制、保存和删除缓存边界。

本轮新增 `frontend/src/exploration-connection.js`。它使用独立档案 revision 和缓存，复用服务器主体与跨标签 Web Lock；预览不切换，明确确认后才使用服务器档案。复制仅允许写入空服务器档案，只传输已确认的证明、资本/河流关联、方向与未知，不上传探索原始回答，也不删除浏览器原件。响应丢失保留原幂等键，版本冲突、会话失效或主体变化停止提交并保留页面内容。

探索页和个人地图读取当前激活档案；地图删除服务端证明时提交受控变更集。服务端主体删除或用户清理删除结果待核对的缓存时，同时清除对应档案连接缓存，原始浏览器档案保留。同步页把工作区与探索档案分开展示和确认，避免把两类数据的部分成功误报为一次整体同步。

验证结果：

- `npm test`：26 个测试文件通过；新增显式启用、本地副本保留、空档案复制、响应丢失重放、档案版本冲突、换主体、无 Web Locks 和删除后缓存清理覆盖。
- `npm run check`：33 个浏览器/共享模块通过语法、入口、资产与动效约束检查。
- `npm run check:api`：真实内存 HTTP 服务加载 32 个浏览器模块，并通过会话、规则分析、档案提交、工作区并发重试、导出删除检查。
- 同步页 DOM 回归覆盖档案预览、复制确认、取消、失败反馈与重复操作保护。
- `git diff --check` 通过。
- 使用一次性 PostgreSQL 16.4 数据库、持久模式 Node 服务及临时 Playwright 1.63 / Chrome for Testing 153，`scripts/browser-profile-sync-check.mjs` 在 1440px 与 390px 触控模拟视口通过：显式复制本地确认档案、服务端探索保存、跨页面刷新恢复、本地/服务器切换、地图投影、两个真实标签的陈旧提交保护、实际导出下载流、二次确认删除、删除后会话 401、服务器档案缓存清理、本地副本恢复、页面异常及横向溢出检查。

临时 PostgreSQL 容器、浏览器、下载分片和运行库已在验证后停止并删除，没有进入生产依赖。触控模拟不等于实体设备，字体细节仍未完成实体视觉验收；账号和跨设备身份恢复仍未实现。
