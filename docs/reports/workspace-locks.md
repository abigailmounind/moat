# 连接锁边界

日期：2026-09-11。

原连接层在没有 Web Locks 时仅使用单实例 Promise 队列，两个页面可能覆盖共享待提交记录。现服务器连接操作要求跨标签锁；缺失锁、访问能力异常或申请失败返回 lock_unavailable，不发请求也不更改缓存、待重试记录或保存位置。已存内容继续可读；纯本地读写不依赖锁。

新增回归覆盖缺失/异常/拒绝三种情况，对刷新、预览、重试、切换、连接及保存核对无网络和数据变化；并确认恢复锁后安全重试，以及纯本地读写仍可用。现有共享锁并发和故障恢复案例继续通过。

npm test：20 个测试文件全部通过。npm run check、git diff --check 通过。测试使用锁替身，不是实际浏览器并发验收；未运行 PostgreSQL。没有新增依赖、改动布局或迁移用户数据。
