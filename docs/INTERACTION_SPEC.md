# 交互规范 · 我的河 · 三河总览 V1.0

- 用途：定义首个可运行纵向切片的四个核心状态、信息层级和操作规则。
- 状态：文档 V0.1；目标体验 V1.0。四态范围与地图优先级为当前 source of truth；触发、退出、键盘和移动端细节为本次交接的实现建议，等待原型验证。
- 最后更新：2026-09-08

## 1. 页面信息层级

**三河地图 > 人生节点 > 当前状态 > 下一步行动 > 导航与辅助信息。**

| 区域 | 展示内容 | 约束 |
|---|---|---|
| 中央地图 | 三条主河、各自支流、证明节点、雾与未来分叉 | 页面主角，所有状态共用同一空间结构 |
| 河流标签 | 生存之河、能力之河、热爱之河及简短状态 | 像地图注释；文字补充颜色与形态 |
| 左侧导航 | 我的河、探索、未来路径、护城河计划等模块入口 | 轻量；当前切片无需实现所有模块 |
| 顶部 | 页面名称与用户入口 | 保持留白，避免堆叠统计 |
| 右侧行动区 | 当前最相关的下一步 | 建议最多一个主行动、一个次行动 |
| 底部状态 | 必要的探索状态、节点或方向数量 | 仅显示有数据支持的信息；低视觉权重 |

地图不可被详情面板完全覆盖。移动端优先保留地图上下文，辅助区可折叠；详情可转为底部抽屉。装饰性纹理不承担交互目标。

## 2. 默认态

- **触发方式**：进入「我的河」，或关闭当前详情与分叉后返回。
- **视觉变化**：首次进入按动效规范显现地图；后续进入建议直接恢复稳定地图。三河清晰可辨，主河从中央自然延伸；已知节点与柔和雾区共存。
- **展示信息**：三河名称、各自简短状态、少量重点节点，以及当前最相关的下一步行动。普通证明按需显示，避免满屏标签。
- **退出方式**：指向或聚焦河流进入预览；点击节点打开证明；使用未来分叉入口展开方向；导航可离开页面。
- **无障碍建议**：页面提供地图文字摘要及按河组织的可操作入口。河流与节点具有可读名称、明确焦点样式，键盘顺序遵循三河及各自节点，装饰层不进入焦点序列。
- **移动端建议**：轻点河流标签触发与 Hover 等价的摘要；轻点节点查看详情。关键内容无需缩放或悬停才能获得。

## 3. Hover 一条河

- **触发方式**：指针进入某条主河或其标签；键盘焦点到达对应河流入口。触控端轻点标签。
- **视觉变化**：该河、相关支流和关联节点轻微增强；其余河流略淡但保持可辨。展开局部标签或轻摘要，不改变河道几何，不重新布局。
- **展示信息**：河名、当前方向的简短解释、相关资本和代表性证明摘要；需要补充的信息可显示为待探索。证据数量仅使用实际数据。
- **退出方式**：指针离开河流及摘要区域后收起；焦点离开后恢复默认；触控端点空白、关闭入口或再次点选收起。切换到另一条河时替换当前预览。
- **无障碍建议**：Hover 信息同样可由键盘访问；焦点与指针进入摘要时保持内容可见。提供 Escape 关闭方式。若摘要含操作按钮，焦点必须能进入，避免只用不可聚焦的提示框承载操作。
- **移动端建议**：以轻点触发固定摘要，不依赖模拟鼠标悬停；摘要中提供明确的证明和未来方向入口。

## 4. 点击证明节点

- **触发方式**：点击或轻点节点；键盘聚焦节点后按 Enter / Space。
- **视觉变化**：节点进入选中态，轻微强调其相关支流或主河；打开证明详情卡。地图保持位置稳定，避免大幅镜头移动。
- **展示信息**：证明名称、经历或作品类型、发生时间（若有）、用户的实际角色与贡献、可用结果或来源、支撑的资本和河流、证据局限或待补内容。缺失信息明确标注，不编造证明细节。
- **退出方式**：点击关闭或按 Escape；非模态卡可点地图空白收起。关闭后焦点返回原节点；若节点已不可见，返回所属河流入口。点击另一个节点替换详情，避免叠加多张卡。
- **无障碍建议**：详情具有标题与清晰语义。使用模态抽屉时焦点限制在抽屉内，关闭后归还；非模态面板保留合理阅读顺序。关联不能只靠颜色表达。
- **移动端建议**：使用可滚动底部抽屉，保留可辨识的地图区域或返回地图入口；关闭按钮始终易于找到。小地图符号可使用更大的透明点击范围，建议触控目标至少 44 × 44 CSS 像素且避免相互重叠。

## 5. 打开未来分叉

- **触发方式**：操作选中河流的未来分叉入口，或点选已可见的未来水道；键盘可使用同等入口。
- **视觉变化**：该河前方的细小未来水道从薄雾中自然显现，依附原河流向外延伸。原有三河与交汇区域保持稳定，分叉始终低于主河层级。
- **展示信息**：候选方向名称、已有资本与证据支持、仍需探索的能力或假设、可继续采取的行动。详情按方向聚焦显示；避免职业匹配百分比与成功概率。
- **退出方式**：关闭、Escape 或再次操作展开入口收起；关闭后恢复打开前的河流上下文。切换河流时收起前一河的分叉详情。收起仅影响视图，不删除已保存方向。
- **无障碍建议**：展开入口暴露展开 / 收起状态，并提供候选方向的可读列表。新增水道不能成为唯一信息载体；焦点留在触发入口，由用户继续进入方向列表。
- **移动端建议**：轻点展开，再点方向查看摘要或抽屉；避免必须沿细水道精确点击。没有方向时提供待探索说明与探索入口，不凭空生成内容。

## 6. 节点层级

| 层级 | 地图表现 | 展开后的职责 |
|---|---|---|
| 普通证明 | 小点或小锚，默认少量标签 | 解释一条具体证据及其支撑关系 |
| 重要经历 | 小图标与简短标签 | 展示项目、实习、研究等较完整经历 |
| 人生里程碑 | 克制的独立地标 | 呈现毕业、转行、重大选择等阶段变化 |

以上经历类型仅为类别示例。三层共享可访问的详情机制；图形大小体现信息层级，不等于证据权重。节点增多时按河、可见区域和交互逐步披露，聚合或缩放阈值后续确定；首切片不强制增加复杂缩放系统。

## 7. 状态协调建议

- 同时保持一个主要详情层：证明详情与未来方向详情相互替换，避免遮挡累积。
- 临时 Hover 不覆盖已打开的主要详情。关闭详情后恢复先前河流上下文。
- 指针在河流与摘要之间移动时不应闪退；视需要采用短暂离开延迟，数值在原型中校准。
- Escape 优先关闭最上层内容；不触发离开页面或删除数据。
- 数据更新、面板打开和动画播放分别管理。动画结束不能作为信息可访问的前提。
- 键盘、触控、减少动态效果三种模式都能走通完整切片。

## 8. 首切片验收与后续范围

必验路径：**进入我的河 → Hover 河流 → 点击证明节点 → 打开未来分叉**。

1. 四态保持同一三河结构和统一视觉语言，无第四条平级河流。
2. 每一步能理解当前河流、所选节点或方向，并能返回上一上下文。
3. 证明详情能解释资本与结论的关联；分叉能解释已有支持与待探索部分。
4. 触控和键盘都可完成同一路径，减少动态效果后信息完整。
5. 地图、文字与操作不依赖 AI 视频、整张静态截图或虚构数据变化。

后续再接「探索 → 结果 → 地图更新」以及「未来路径与护城河计划的独立保存、编辑和关联」。这两条闭环尚未由四态原型验证；长期保存与反复编辑的要求仍必须保留。

## 9. 2026-09-08 修订实现与验证边界

运行时使用稳定 SVG 与 DOM 叠层。指针进入河道/标签显示摘要，点击标签固定摘要，再次点击或 Escape 收起；证明与未来面板互斥。证明打开后聚焦标题，关闭归还原节点；面板内候选切换保留焦点。触发器被替换时转移到新详情标题。河岸不随选择变宽。

窄屏采用地图下方非模态详情区，保留地图与三个中文河流入口；打开后滚动到可阅读位置。桌面详情在右侧滚动，地图保持固定。未实现的完整模块显示筹备中，未来分叉入口是本阶段可用能力。

当前证明与方向均为合成示例；无候选的热爱之河保持空方向说明。实现检查见 reports/stage9-verification.md；后续仍以用户视觉反馈继续校准。
