# 人生护城河 · 我的三河地图

阶段 9 修订版，状态：进行中，等待用户视觉验收。演示页面不会分析或保存个人资料。

## 运行

在项目目录运行 `npm start`（无需安装外部依赖），打开 http://127.0.0.1:4173/ 。需要 Node.js 20 或以上。

`npm test` 检查详情互斥、无候选方向、无效输入、重复切换及数据/几何关联；`npm run check` 检查入口和资源。`node scripts/export-map.mjs` 从运行时几何重新导出 SVG 河流层。

## 可以体验

- 指向河道、聚焦或轻点河名 → 阅读摘要 → 查看证明 → 展开未来分叉。
- 点击证明节点直接阅读来源、贡献、资本关联和局限。示例均为合成案例。
- Escape / 关闭返回原河流；切换详情不改变地图骨架。
- 首次约 4.8 秒沿河显现，可立即查看；常驻流纹、雾呼吸可暂停；显示设置可开启减少动态效果。
- 窄屏通过河流按钮与文字说明完成同一条路径。

## 文件职责

- `src/map.js`：三河填充轮廓、支流、显现遮罩、流纹和雾。
- `src/data.js`：明确标记的合成案例、证明、资本说明与从属方向。
- `src/state.js`：四态协调；`src/app.js`：稳定 DOM 与可访问交互。
- `src/styles.css`：整幅地图布局、动画和响应式。
- `assets/three-rivers/rivers-v2.svg`：可单独复用的透明河流图层；由源代码导出，请从源代码修改后重导出。

真实探索、长期路径与计划编辑、成长记录属于后续阶段，导航已标注筹备中。视觉细节仍须对照高保真稿获得用户验收，自动化检查不能替代这一项。
